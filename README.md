# SHIB/JPY Monitor - OKJ
OKJ Public WebSocket: books / trades / tickers for SHIB-JPY.

Render Start Command:
`python -m uvicorn main:app --host 0.0.0.0 --port $PORT`

Endpoints: `/api/health`, `/api/analysis`, `/api/orderbook`, `/ws`

Root files only. No frontend/, backend/, app.py, or __pycache__/.
